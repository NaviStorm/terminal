# Assistance — mTerm

Besoin d’aide avec une session, un volet ou un profil de couleurs dans mTerm ?

Pour signaler un problème ou proposer une amélioration, écrivez à [app@perouges.eu](mailto:app@perouges.eu).

Pour un signalement, indiquez si possible les éléments suivants.

- Le modèle de votre Mac et la version de macOS.
- La version et le numéro de build affichés dans **mTerm → À propos de mTerm**.
- Les gestes ou la commande qui reproduisent le problème, le résultat attendu et celui que vous observez.
- Si le problème concerne l’affichage, le profil utilisé et le nombre d’onglets ou de volets ouverts.

Une capture d’écran peut aider à comprendre un défaut d’affichage. Pensez à masquer les mots de passe, les jetons d’accès et les adresses de serveurs privés visibles dans le terminal.

## Questions fréquentes

### Comment afficher deux sessions côte à côte ?

Dans le menu **Session**, choisissez **Scinder verticalement** (⌘D). Pour placer les sessions l’une au-dessus de l’autre, choisissez **Scinder horizontalement** (⇧⌘D).

### Comment retrouver mes volets après en avoir agrandi un ?

Appuyez sur **⇧⌘Entrée** pour rétablir la disposition précédente. Les commandes des autres volets continuent de s’exécuter pendant le zoom.

### Pourquoi seule la barre de titre est-elle visible ?

Si vous avez activé le repli de fenêtre, double-cliquez à nouveau sur la barre de titre pour retrouver la session. Vous pouvez désactiver ce geste dans **mTerm → Réglages → Général**.

### Comment conserver davantage de lignes dans le terminal ?

Dans **mTerm → Réglages → Général**, modifiez **Historique des nouvelles sessions**, puis ouvrez un onglet ou un volet. La limite par défaut est de 1 000 lignes par session.
